# Манифест автообновления

`latest.json` здесь **намеренно не хранится в git** — его пишет
`scripts/release-apk.sh` прямо на VPS.

Причина: манифест описывает APK, которого в репозитории нет (`web/*.apk` в
.gitignore из-за размера). Если держать манифест в git, он неизбежно
разъезжается с реальным файлом на сервере, а любой `rsync web/` затирает
боевой манифест устаревшим — приложения начинают видеть версию, которой на
сервере ещё не существует, и упираются в несовпадение sha256.

Выложить релиз:

```
cd mobile && eas build --profile preview --platform android
# скачать артефакт по ссылке из вывода
./scripts/release-apk.sh <путь-к-apk> --notes "Qué hay de nuevo, en español"
```

Скрипт сам сверяет versionCode с опубликованным, заливает APK атомарно и
только потом обновляет манифест.
