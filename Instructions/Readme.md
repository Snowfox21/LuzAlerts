# LuzParaguay (Рабочее название)
Приложение для мониторинга отключений электроэнергии в Парагвае в режиме реального времени.

## Основные функции
* **Официальный мониторинг:** Автоматический сбор данных о плановых отключениях с портала ANDE.
* **Краудсорсинг (Геометки):** Пользователи могут отмечать отсутствие света на карте в один клик.
* **Умные уведомления:** Рассылка в WhatsApp при изменении статуса электроснабжения в выбранном районе.
* **Интерактивная карта:** Визуализация проблемных зон города.
