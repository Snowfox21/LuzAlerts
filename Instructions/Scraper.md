Спецификация Парсера (Data Engine)

Источники (Sources):

1.  Primary: [подозрительная ссылка удалена] (Плановые работы).
2.  Secondary: Internal API consultas.ande.gov.py (Аварийные отключения).
3.  Social: Twitter @ANDEOficial (Оперативные новости).

Алгоритм обработки данных:

1.  Fetch: Ежечасный запрос к источникам.
2.  Clean: Нормализация названий районов.
3.  Geocode: Поиск координат через OpenStreetMap API.
4.  Compare: Проверка на дубликаты.
5.  Broadcast: Отправка триггера в систему уведомлений.

Технологический стек:

  - Python 3.10
  - Scrapy или Playwright

Практическая оптимизация (NIS и Фидеры):
Использовать Nro de NIS (номер счета) для автоматического определения Nro de Alimentador (номера фидера/линии). Это позволит уведомлять пользователя адресно, когда отключается конкретно его линия. Это на порядок точнее, чем мониторинг по районам.
