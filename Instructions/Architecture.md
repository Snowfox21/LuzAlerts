# Архитектура системы

## Компоненты
1.  **Scraper (Python/Node.js):** Скрипт, который раз в 15 минут проверяет раздел "Cortes Programados" на сайте ANDE.
2.  **Backend API:** Обрабатывает метки пользователей и хранит базу данных активных инцидентов.
3.  **Database:** PostgreSQL + PostGIS (для работы с геометками и координатами).
4.  **Frontend:** Flutter или React Native для кроссплатформенности (iOS/Android).
5.  **WhatsApp Gateway:** Интеграция через Twilio или официальный WhatsApp Business API.

## Потоки данных
* **Официальный путь:** ANDE -> Scraper -> DB -> Push-уведомление.
* **Пользовательский путь:** App -> Геометка -> DB -> Проверка соседей (валидация) -> Общий статус района.
